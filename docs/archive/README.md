# Documentation Archive

Everything under `docs/archive/` is historical.

Do **not** use archived documents as current deployment, backup, build, release,
or rollback instructions.

Current operational authority:

- Backend: `/OPERATIONS.md`
- Backend engineering policy: `/AGENTS.md`
- Frontend exact build commands: frontend `/README.md`
- Frontend release workflow: frontend `/RELEASE.md`

Historical release documents are retained to explain prior incidents, migrations,
benchmarks, and rollout decisions.
